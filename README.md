# Hồ sơ GitHub của mvd-team

Repository này chứa nội dung giới thiệu hiển thị trên trang Overview của organization [mvd-team](https://github.com/mvd-team).

## Nội dung hiển thị

Chỉnh sửa [profile/README.md](profile/README.md) để cập nhật phần giới thiệu organization, hệ thống YT Gen, các repository và liên kết tài liệu.

Theo [hướng dẫn của GitHub](https://docs.github.com/en/organizations/collaborating-with-groups-in-organizations/customizing-your-organizations-profile), README công khai của organization được đặt tại `profile/README.md` trong repository `.github` công khai. Để hiển thị trên Overview, đưa file lên nhánh mặc định của repository này.

## Lưu ý khi cập nhật

- Giữ nội dung giới thiệu phù hợp để hiển thị công khai.
- Không đưa API key, token, tài khoản hoặc dữ liệu nội bộ vào README.
- Các liên kết tới repository riêng tư chỉ mở được với người có quyền truy cập.
- Các liên kết tài liệu dùng `HEAD` để theo nhánh mặc định của từng repository; tài liệu chỉ xuất hiện khi thay đổi đã được đưa lên nhánh đó.
